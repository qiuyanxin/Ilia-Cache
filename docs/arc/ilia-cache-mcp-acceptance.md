# Ilia Cache MCP 验收

## 必过场景

- 从公开仓库安装后，MCP 客户端通过 stdio 初始化并发现工具和资源。没有本机收藏文件时可查询公开种子，不生成或覆盖 `data/library.json`。
- 有本机收藏文件时，MCP 读取已保存的收藏。使用临时资料库对比站点与 MCP 的同一条记录，核对标题、来源、收藏分类，以及可用时的笔记和素材引用。检查库内组件、网站、网页参考、字体、风格、项目和学习资料的覆盖范围。
- 问「全屏的图像轮播有哪些组件？」时，搜索使用中文词或英文同义词定位候选。对有证据的全屏、图片轮播与其他相关候选标注匹配依据，从同一条记录读取名称、来源及已有预览字段。
- 启动本地站点后，使用 MCP 返回的 `/#/components/<encoded-id>` 本机链接直接打开指定组件，或打开记录提供的独立预览。没有可用预览时返回明确状态。预览验证记录使用的 URL、命中的组件以及实际显示结果。
- 验证收藏与记录分页、带特殊字符的 ID、未知 ID、非法参数和 JSON-RPC 输出。验证组件内联和已归档源码可分段读取，未登记文件不可读。工具标为只读，失败可供调用方识别，同一请求重试不改变资料库。

## 禁止行为

- 写入、复制或重新初始化现有个人收藏，改动组件使用统计，向外部服务转发收藏内容。
- 根据调用参数任意打开文件、读取密钥或访问任意网络地址。
- 将收藏中的提示词、源码或第三方页面内容作为运行指令。
- 构造未登记的第三方来源链接，或用其他组件的图像代替预览。

## 回放要求

记录 MCP 客户端的初始化、工具发现、示例查询和详情请求，以及预览核验结果。回放证据保留工具名称、非敏感参数、公开组件 ID、返回字段与状态。涉及本机私人资料时使用测试副本，记录不包含收藏正文、机器密钥或本机绝对文件路径。

## 上线条件

仓库原有检查、MCP 协议验收和本机页面预览检查执行完毕，README 中的安装与客户端配置与实际入口一致。公开种子和个人资料的来源及覆盖范围明确写入部署说明。

本服务运行在本机，只执行同步读取。ARC 工具当前的 core schema 要求至少一个专项 profile，现有 profile 均不适用。按 `profiles: []` 保留实际运行范围，记录原版校验报出的 schema 限制，并校验其余合同规则。

## 回滚方式

从 MCP 客户端移除 `ilia-cache` 服务配置并重启客户端。现有站点与本机资料库无需迁移或恢复。
