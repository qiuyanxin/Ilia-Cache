# 本机数据迁移与恢复

日常浏览、编辑和 MCP 查询使用 `ILIA_DATA_DIR` 下的 `library.sqlite`。不设置环境变量时使用仓库的 `data/` 目录。浏览器的历史导出、旧版 `library.json`、附件和源码包保留在本机。Node.js 需为 22.16 或更新版本。

## 从原版迁移

先从原网站地址与浏览器配置分别导出旧资料。浏览器按协议、域名和端口各自存储，`localhost` 与 `127.0.0.1` 可能各有一份。复制完整旧 `data/` 到单独目录，停止对副本的其他写入，再将以下命令指向副本。

```sh
export ILIA_DATA_DIR=/path/to/disposable-library-copy
node scripts/library-db.mjs migrate --dry-run
node scripts/library-db.mjs migrate
node scripts/library-db.mjs import-browser /path/to/browser-export.json /path/to/new-conflicts.json
node scripts/library-db.mjs status
npm start
```

按 ID 核对收藏、待选、项目、笔记、附件与预览。浏览器独有的条目补入数据库。同 ID 内容不一致时保留 SQLite 当前值，冲突文件保留两份内容，供核对后合并。冲突文件包含私人内容，留在本机。新版启动会读取现有数据库，公开种子的后续更新可以通过 `import-seed` 预检后导入。

各项库内数据按记录保存，FTS5 是由记录生成的搜索索引。本机继续开放网页 JSON 导出，用于交换资料和兼容旧版。

## 备份、验证和恢复

```sh
node scripts/library-db.mjs backup /path/to/new-backup-dir
node scripts/library-db.mjs verify-backup /path/to/new-backup-dir
node scripts/library-db.mjs restore /path/to/new-backup-dir /path/to/new-library-dir
```

备份包含数据库快照、兼容 JSON、旧 JSON 副本及附属文件的校验清单。恢复目标使用新目录。开一个独立端口和全新的浏览器配置，检查恢复版的搜索、个人工作台和附件后，再调整正式本机启动目录。需要回旧版时先备份新版已写入的数据，通过兼容导出与旧版资料对照后切换。
