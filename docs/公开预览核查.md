# 公开组件预览核查

原先只有来源链接的 416 个组件中，已有 30 个补上官方预览。目录现有 850 个组件，其中 218 个接入官方视频、25 个接入官方静态图、216 个使用本地授权 Canvas 动效，另有 5 个嵌入官方专用预览。其余 386 个提供来源链接，其中 200 个 React Bits 音色可以直接打开选中相应音色的官方页面。

## 本次新增

- Motion Prompt 画风样例 193–216 对应作者发布的 `style-01.webp` 至 `style-24.webp`。Chrome 在跨站页面中加载了全部 24 张图，实测尺寸为 1078 × 416。图片由上游托管。 [上游图片授权和编号映射](https://github.com/showheyohtaki/motion-prompt/blob/683ecca0548a1754ada141d10dc3a009d4c59bef/packs/artstyle/pack.js#L5-L55)
- React Bits Shape Grid 页面明确关联一张同名组件图。Chrome 在跨站页面中加载成功，实测尺寸为 1200 × 630。 [组件官方页](https://reactbits.dev/backgrounds/shape-grid)
- SmoothUI 的 Exposure Slider、Unlock Face ID、Scrubber、AI Task List、Music Toggle 文档声明了各自的 `/preview/<slug>?embed=1`。Chrome 在仅开启脚本的 iframe 沙箱中成功渲染五个独立示例。Siri Orb 在相同沙箱中访问 `localStorage` 时触发错误，因此保留原站入口。 [SmoothUI 官方预览架构说明](https://smoothui.dev/docs/guides/changelog)

## React Bits 逐音色来源入口

React Bits Sound Lab 的官方分享地址使用 `#sound=<id>`。公开目录的 200 个音色 ID 与固定版本的 Interface 和 Video 两组官方清单逐一吻合。Chrome 在独立会话中打开 Halo、Tide 和 Reveal 的分享地址后均选中对应音色，点击播放按钮后由 Web Audio 开始播放。Ilia 页面保留这部分的「来源链接」状态，用户前往原站播放。通用的 Sound Engine 条目继续链接到 Sound Lab 首页。 [官方分享协议](https://github.com/DavidHDev/react-bits/blob/701a8acc34f718b305d1ff0cc7d4700df0e1f1c9/src/tools/sound-lab/sounds/share.js#L65-L91)、[Interface 音色清单](https://github.com/DavidHDev/react-bits/blob/701a8acc34f718b305d1ff0cc7d4700df0e1f1c9/src/tools/sound-lab/sounds/interface.js)、[Video 音色清单](https://github.com/DavidHDev/react-bits/blob/701a8acc34f718b305d1ff0cc7d4700df0e1f1c9/src/tools/sound-lab/sounds/video.js)

开源组件库和网站使用同一个 `officialPreviewForRecord` 选择官方预览。组件 ID 与原始来源必须同时吻合。图片和 iframe 由浏览器直接访问上游。获准内嵌的条目提供「打开交互预览」，用户点击后在沙箱中加载。新标签页入口直接打开同一个官方预览，保留浏览器自己的嵌入限制。
