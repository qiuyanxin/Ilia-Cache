# Ilia 设计收藏

个人网站入口与组件、网页参考整理库。原始 Chrome 收藏与 Obsidian 文件未改动。

## 公开仓库边界

公开仓库包含应用代码、设计规范、网站与 850 个组件的可公开索引、281 个页面参考、218 种字体、59 组设计风格，以及许可允许再分发的 MIT 组件文件。首次运行会从 `public/seed.json` 建立本机资料库。

个人收藏、Pinterest 审美图、上传素材、运行时生成的 `data/`、验收截图，以及禁止整库再分发的第三方源码归档不会提交到 Git。这些组件在公开库中仍保留标题、说明、提示词、预览、第一来源和许可信息，需要源码时请回到原站获取。第三方设计、代码与素材仍归原权利人所有，使用时须遵守各自许可。

## 打开

双击 `启动设计收藏.command`，或在本目录运行 `npm start`，打开 http://127.0.0.1:4317 。只在本机运行，Node.js 22+，不需要 npm install。

## 这次的使用方式

1. 左侧是网站索引，按域名归并。106 条网站链接整理为 87 个网站入口，原先混在网站中的 1 条组件链接已归入组件库，www 前缀合并。
2. 名称上悬停，旁边弹出带圆角、阴影与淡入效果的真实首页截图；移开隐藏。键盘聚焦也可预览。
3. 单击名称会打开原网站，同时在本页右侧选择对应网站；也可点击收藏数量，只切换右侧。
4. 右侧粘贴具体组件、作品集或网页链接，选择组件 / 网页参考，再点添加。标题、公开图片与视频会自动读取，按域名放在一起，以原比例瀑布流展示。
5. 已有的文档和工具链接也会在对应网站下保留，首次选择时自动补充公开素材。部分站只公开分享封面；需要登录、反爬或纯客户端内容可能读不到。失败时保留链接，可手动上传预览。
6. 右上角白色 / 黑色切换，刷新后保留主题选择。风格参考用户提供的 Sheen board 本地源码：中性灰阶、细边框、分层卡片与轻微高光。

网站说明分成能找到什么、适合做什么：87 条逐项提炼，其中 84 条核对到官网公开内容，2 条访问受限、1 条分享链接不完整。用途分类是整理建议；费用与许可没有依据的显示待核实。

## 首页截图和媒体

四个常用网站使用本地保存的真实首页截图。其他站点首次悬停时使用 Thum.io 的公开 URL 截图接口生成，可能较慢，也可能受原站限制。只发送公开首页地址，不发送收藏库或笔记。接口依据 https://www.thum.io/documentation/api/url 。

具体收藏媒体直接取自原网页的公开图片、视频及元数据；不把首页截图冒充具体组件效果。Designeer 视频页支持读取懒加载 JSON，且排除相关推荐素材。视频支持原生播放和暂停。

## 学习提示词

保留英文与来源，逐段中文讲解工具、依据、原理、参数和复现方式，支持学习笔记与 Markdown 导出。

尚未配置 OPENAI_API_KEY，在线 AI 讲解没有接通。现可用：粘贴原文 → 复制学习任务 → 在 Codex / ChatGPT 获取讲解 → 粘回右侧 → 保存笔记。内置示例明确标注非实时 AI。

服务器端 `/api/learn` 已预留真实 Responses API 路由。之后若接通，在服务器环境变量配置 OPENAI_API_KEY；可选 OPENAI_MODEL（默认 gpt-4.1）。密钥不放在网页和浏览器存储中。只发送当前提示词与来源，不发送整个收藏库。

## 页面路径

首页和各资料库使用可直接分享的 Hash 路径：`#/home`、`#/websites`、`#/components`、`#/pages`、`#/fonts`、`#/styles`、`#/aesthetic`、`#/projects`、`#/learning`、`#/sources`。开源边界与后续导航站方案见 [OPEN_SOURCE_PLAN.md](./OPEN_SOURCE_PLAN.md)。

仅供学习使用。第三方设计、代码与素材的权利归原权利人所有，使用须遵守其许可。

## 保存与备份

新增收藏、媒体链接、精选和笔记保存在当前浏览器、当前地址的 localStorage。主题单独保存。移除案例采用归档标记，可立即撤销。JSON 导出含收藏与笔记，导入采用合并。

更换浏览器、端口、127.0.0.1 / localhost 地址，或清理网站数据时不会自动迁移，先导出备份。原始种子在 public/seed.json，没有自动同步 Chrome / Obsidian，也没有云同步或公开发布。

## 检查

`npm run check` 做语法检查，`npm test` 检查域名归并、链接保留、媒体提取和本地地址拦截等关键行为。浏览器实测记录见 verification/验收记录-v2.md。

## 组件收藏与后续使用

左侧「我的组件库」按按钮、导航、轮播、卡片等用途分类。可单独添加链接、原文提示词和源码文件。详情中可交互预览、保存和复制提示词、查看单个源码文件、复制给 Agent、下载 ZIP。LeiBox 的详情页会读取它公开的独立 HTML、各框架源码和复刻提示词；其他网站不保证提供这些文件，缺失时可手动上传。

网站列表可切换 Swipe deck 卡组，左右拖动或按方向键浏览，向右加入精选。每行提供添加收藏、修改名称与域名、移除及撤销。图标读取原站 favicon。Pull cord 位于右上角，点击、键盘 Enter / Space 或下拉切换黑白；说明文字只在悬停或键盘聚焦时显示。自动拉绳已取消，避免页面自行切换主题。

收藏保留浏览器副本，同时同步到 `data/library.json`；组件索引在 `data/component-index.json`，每个组件的提示词和源码在 `data/components/<id>/`。以后对 Agent 说「从我的组件库找弹性图片对比」，并提供这个项目目录即可。索引和源码不通过公共静态目录提供。

原始 DesignBookmark 文件保留在 `references/designbookmark/`。适配版为无依赖 HTML/CSS/JS，保留原弹簧；预览用 sandbox 隔离。ZIP 中的第三方代码仍可能使用远程图片、字体或框架依赖，文件下载不代表这些依赖已经安装。自动中文讲解仍需配置 AI 连接；未连接时可复制学习任务到 Codex。

## 随手收集、风格与审美积累

顶部随手收集或 ⌘J 打开一个粘贴框。原文、链接、图片和视频可以直接收进来，按内容规则分到组件、图片提示词、视频提示词等类别，无法判断的进入待整理。组件提示词同时加入组件库。附件最大 100 MB，保存在本机 `data/assets/`，浏览器仅保存文件索引。

设计风格包含所给 Lilian 页面现有的全部 44 组中英文提示词，来源和原有图片出处保留；另有用户指定的 6 类常用风格，其整理文案和来源原文分开。点击透明玻璃文件夹可以复制提示词、添加素材，也能新建风格。原始风格索引是 `public/design-styles.json`，用户修改写入 `data/library.json` 的 styles 字段。

审美积累支持自建分类、本机素材和 Pinterest 公开链接导入。当前提供的「插画风格」收藏夹已导入 22/22 张图。刷新按钮重新读取公开页面、按图片 ID 去重；这是公开收藏夹导入，并非 Pinterest 账号 OAuth 连接，不读取私人收藏。Pinterest 未公开的内容不会被冒充导入成功。

新的导航和控件使用原生 HTML/CSS/JS 适配：折叠侧栏、Roll links、Word roll、Command button、Copy button、Bottom bar、Stack panel。弹簧集中在 `public/springs.mjs`，原始代码保留在 references。设置里的备份入口继续使用原有导入/导出逻辑。

JSON 导出保存收藏清单、提示词、源码与素材地址；跨机器搬迁时请同时保留 `data/assets/`，JSON 本身不包含本地图片和视频文件。
